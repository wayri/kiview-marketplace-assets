# KiCad Visual Review for GitHub and GitLab

Review saved KiCad schematics and PCB layouts in Chrome, on supported repository pages or from a local project folder. KiCad installation is not required for the browser viewer.

The viewer includes saved component/net/layer inspection, 2D measurement, copper net-name labels, supported 3D assets, BoM/assembly variants, testpoint tables, saved analytics/reports, supported fabrication/PDF viewing and engineering calculators. Supported repository revisions can be compared. Review notes stay local unless you explicitly publish through an authorized provider account.

Native KiCad checks and simulation solvers are not run. Unsupported file constructs and missing model dependencies can limit results. Independently verify engineering decisions.

## KiCad versions and VS Code companion

Recognized KiCad 8, 9 and 10 constructs are supported within documented limits. KiCad 10 has native reference fixtures; 8/9 coverage is narrower. Newer versions are warned previews. [Version matrix and feature limits](COMPATIBILITY.md).

Prefer reviewing beside your code? [Install the VS Code edition](https://marketplace.visualstudio.com/items?itemName=wayri.kicad-visual-review). Both editions work independently and portable exports transfer supported review state. Browser-specific account and standalone engineering tools are not promised in VS Code.
